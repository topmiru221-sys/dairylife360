# DairyLife 360｜現場問題解決平台

本分支為 **V18.5.18 恢復重建測試版**，由 GitHub main（V18.5.17.10）安全延伸。2026-10-30 原 Work 未發布內容尚未恢復，因此這是依據已知工作紀錄重新實作的候選版，並非原始檔案逐位元復原。

## 使用者功能

- 首頁保留八個主要入口，原有 DHI、TMR、營養、問診、SOP、AI 牛寶及相關工具繼續由導覽進入。
- 現場工具箱新增七個工作領域：新生犢牛、繁殖、蹄病跛行、環境熱緊迫、視覺評分、清潔消毒與完整生物安全。
- 工作表提供個案、負責人、觀察、行動、專業覆核、複驗日期、現場檢核、追蹤狀態及資訊完整度；缺失時不能顯示可結案。
- 每個領域均有緊急警訊、示範資料、複製摘要、TXT 匯出及相關模組入口。資料僅在瀏覽器中暫存，關頁即消失。
- 清潔消毒頁保留濃度計算機的百分比、mL/L 及 ppm 模式，並加入顯眼入口；工作台可一鍵切換。
- 對外頁面移除治理、商業規劃及開發藍圖主區段，舊網址導回首頁；保留專業模組。

## 初步檢查與限制
