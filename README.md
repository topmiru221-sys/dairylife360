# DairyLife 360｜V18.5.17.10 驗收候選

## 用法

1. 下載並開啟根目錄 `index.html`（建議 Chrome／Edge）。無須登入，不需要資料庫。
2. 進入「生命週期管理」，在 Fresh 21 下方找到「產後子宮健康 × 現場解方」。亦可由 Fresh 21 按鈕或疾病知識庫快捷鍵前往。
3. 輸入產後天數、精神採食、胎衣與分泌物，按「產生現場分流建議」。
4. 如有獸醫檢查之 PMN% 可輸入；參考時窗與方法限制會顯示。
5. 有需要時複製摘要或匯出 TXT；本網站不會儲存輸入，關閉頁面資料將消失。

## 注意事項

- 現場分流不構成確診或用藥處方；重症應立即聯絡獸醫。
- PVD 陰道分泌物不等於已確診子宮內膜炎。子宮頸炎與陰道炎應鑑別。
- PMN 示範界線僅供特定採樣方法及產後日數參考，不應取代獸醫診斷。
- 胎衣超過 24 小時仍未排出需追蹤，不可粗暴人工剝離。
- 網頁仍維持 V18.5.17.9 的專業模組與原有品牌牛寶；本版不做架構或首頁改版。
