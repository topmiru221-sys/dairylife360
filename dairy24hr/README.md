# DAIRY 24HR｜像素牧場試玩版 P0.1

這是可在瀏覽器中直接執行的獨立單檔案遊戲原型，內容取材自《DAIRY 24HR》劇本 V3.1。**沒有修改原版 DairyLife 360 首頁。**

## 開始遊玩

開啟本資料夾的 [`index.html`](./index.html)，或使用本儲存庫 GitHub Pages 對應的 `/dairy24hr/` 網址（需 Pages 已設定從 `main` 根目錄發佈）。

- 電腦：方向鍵／WASD 移動、E／空白鍵互動、滑鼠點擊移動或點任務標記。
- 手機：左下角方向鍵及互動按鈕，或直接點擊黃色任務標記。
- 自動儲存：瀏覽器 localStorage。按「新的一局」重玩，可遇到不同支線事件。

## 內容

等角斜俯視的方塊牧場；交班、冷卻槽、晨間擠乳四步互動、Fresh Cow、TMR、環控、下午擠乳、黃昏阿伯交班，共八個核心任務，另有數個隨機支線與結局評價。

**目前只是日間可玩切片（P0.1），不是已完成的 24 小時完整版**。正式版會補上夜間、更多角色及更完整的因果事件。遊戲畫面不內嵌牛寶或 DairyLife 360；網站獨立運作。

遊戲內的情境數據為劇本模擬，不得作為專業診療、設備維修或乳品放行標準。
